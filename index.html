Vamos falar de HTML

Bem-vindo à minha página sobre HTML!

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto). É a linguagem que dá estrutura a qualquer página da internet. Não é uma linguagem de programação, porque não tem lógica, condições nem ciclos. Ela apenas descreve o conteúdo: isto é um título, isto é um parágrafo, isto é uma imagem.

Como funciona?

O HTML é escrito com tags, que são marcas entre sinais de menor e maior. A maioria das tags tem abertura e fecho, e o conteúdo fica no meio. Quando abres uma página, o navegador lê essas tags e desenha o resultado no ecrã.

Estrutura básica de uma página

Toda a página HTML tem duas partes principais. O head guarda informações que não aparecem na página, como o título do separador e a codificação de caracteres. O body guarda tudo o que o utilizador vê: textos, imagens, links, botões e formulários.

Tags mais usadas

Os títulos vão de h1 a h6, por ordem de importância. Os parágrafos usam p. Os links usam a, as imagens usam img e as listas usam ul, ol e li. Para agrupar elementos usa-se div. Para mostrar código, usa-se pre com code.

HTML, CSS e JavaScript

O HTML trabalha sempre em equipa. O HTML faz o esqueleto, o CSS trata do visual (cores, tamanhos, posições) e o JavaScript dá comportamento (cliques, animações, dados dinâmicos). Quem quer desenvolver para a web precisa de dominar primeiro o HTML, porque tudo o resto assenta nele.

Porque é importante aprender HTML

Aprender HTML é o primeiro passo para criar sites, e é uma base útil para quem segue áreas como desenvolvimento ou DevOps. Escrever HTML bem estruturado também melhora a acessibilidade e a visibilidade nos motores de busca.
